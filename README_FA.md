# راه‌اندازی Lider Reklam (رایگان برای شروع)

این بسته یک نسخه اولیه دو‌زبانه (ترکی استانبولی و فارسی) برای معرفی کسب‌وکارها و خدمات در سراسر ترکیه است.

## امکانات
- طراحی واکنش‌گرا برای موبایل و کامپیوتر
- تغییر زبان ترکی/فارسی
- دسته‌بندی و جست‌وجوی آگهی‌ها
- ارسال آگهی توسط کاربران با وضعیت `pending`
- نمایش عمومی فقط برای آگهی‌های `approved`
- شماره تماس و پیوند واتساپ/وب‌سایت در آگهی‌ها

## مرحله ۱ — ایجاد پایگاه داده رایگان
1. به https://supabase.com بروید و حساب بسازید.
2. یک پروژه جدید در پلن Free ایجاد کنید و رمز پایگاه داده را در جای امن نگه دارید.
3. از بخش SQL Editor، محتوای فایل `schema.sql` را اجرا کنید.
4. از Project Settings / API، مقدار Project URL و کلید publishable (یا anon قدیمی) را کپی کنید.

نکته: پلن رایگان ممکن است محدودیت داشته باشد و پروژه‌های غیرفعال را متوقف کند؛ برای اطلاعات جاری صفحه رسمی قیمت‌ها را ببینید.

## مرحله ۲ — اتصال سایت به Supabase
1. فایل `config.js` را باز کنید.
2. مقدار `SUPABASE_URL` را با Project URL عوض کنید.
3. مقدار `SUPABASE_ANON_KEY` را با کلید publishable/anon عوض کنید.
4. فقط کلید عمومی publishable/anon را در سایت قرار دهید. هرگز `service_role` یا کلید secret را در سایت منتشر نکنید.
5. `index.html` را در مرورگر باز کنید تا ظاهر را آزمایش کنید. برای ارسال واقعی فرم، اتصال و SQL باید درست باشد.

## مرحله ۳ — انتشار رایگان
پیشنهاد: Cloudflare Pages با آدرس رایگان `*.pages.dev`.
1. یک حساب در https://dash.cloudflare.com بسازید.
2. در Pages، یک پروژه جدید ایجاد کنید و روش Direct Upload / upload assets را انتخاب کنید (نام گزینه‌ها ممکن است تغییر کند).
3. فایل‌های `index.html`، `style.css`، `app.js` و `config.js` را در یک پوشه قرار دهید و همان خروجی را منتشر کنید.
4. Cloudflare یک آدرس رایگان `*.pages.dev` می‌دهد.
5. بعد از هر تغییر، نسخه جدید را منتشر کنید.

مرجع رسمی محدودیت‌های Pages:
https://developers.cloudflare.com/pages/platform/limits/

## مرحله ۴ — تأیید آگهی‌ها
- کاربران از فرم سایت آگهی می‌فرستند؛ وضعیت به‌طور خودکار `pending` است.
- برای بررسی، وارد Supabase Dashboard > Table Editor > `listings` شوید.
- آگهی مناسب را باز کنید و مقدار `status` را به `approved` تغییر دهید؛ برای رد کردن، `rejected` را انتخاب کنید.
- فقط آگهی‌های `approved` در صفحه عمومی نمایش داده می‌شوند.

برای امن‌تر بودن، ابتدا خودتان حساب Supabase را نگه دارید و دسترسی داشبورد را به دیگران ندهید. فایل SQL یک جدول `site_admins` نیز ایجاد می‌کند تا بعداً پنل مدیریت اختصاصی و امن اضافه شود. این نسخه اولیه از پنل مدیریت داخل سایت برخوردار نیست؛ تأیید در داشبورد Supabase انجام می‌شود.

## نکات ضروری قبل از انتشار عمومی
- قوانین حریم خصوصی، شرایط استفاده و روش درخواست حذف/اصلاح اطلاعات را اضافه کنید.
- از آگهی‌دهندگان اجازه انتشار اطلاعات تماس بگیرید.
- آگهی‌های جعلی، محتوای غیرقانونی و اطلاعات شخصی حساس را منتشر نکنید.
- فرم فعلی محدودیت‌های اولیه سمت پایگاه داده دارد؛ برای استفاده گسترده، captcha/rate limit و بررسی ضداسپم اضافه کنید.
- این نسخه فعلاً بارگذاری عکس ندارد؛ برای افزودن عکس، Supabase Storage و بررسی نوع/حجم فایل لازم است.
- این نسخه اولیه است و قبل از استفاده تجاری جدی باید از نظر امنیت، حریم خصوصی و قوانین محلی بررسی شود.

## فایل‌ها
- `index.html`: صفحه سایت
- `style.css`: ظاهر و طراحی
- `app.js`: زبان، جست‌وجو و فرم
- `config.js`: تنظیمات اتصال
- `schema.sql`: جدول‌ها و سیاست‌های امنیتی پایه
